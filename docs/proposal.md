# MoonBCH：二进制数据块纠错与恢复库

账号：btlqql｜单人项目｜版本：0.1.0｜主要语言：MoonBit｜许可：Apache-2.0

## 解决的问题

校验和只能发现数据损坏，无法恢复内容。MoonBCH为二进制记录、离线文件块及故障注入测试提供可嵌入的BCH编码与硬判决纠错能力；附带带CRC32的块容器与文件CLI，完成编码、注入损坏、纠错和校验的完整流程。

## 核心实现

纯MoonBit实现GF(2^m)运算、本原多项式周期验证、共轭根生成多项式、系统编码、伴随式、Berlekamp-Massey及Chien搜索，返回恢复消息与准确错误位置。支持原始窄义二进制BCH、m=2至12、t=1至64的有效参数及缩短码。运行时不调用Python、C或网络服务。

## 可复现任务

对实际6428字节的bch.mbt源码，以BCH(255,239,t=2)分为216块，每块翻转两位，共432个位错误；文件工具恢复后逐字节相同，SHA-256一致。CRC被改动时拒绝输出，已有目标文件不会被覆盖。错误注入及验证记录随申报材料提供。

## 正确性与独立性

BCH(15,7,t=2)的128条消息及全部0、1、2位错误模式穷举验证，共15,488例；另与独立galois 0.4.11核对66组完整／缩短码的编码、解码和错误位置。区别于Reed-Solomon字节符号擦除编码及LDPC软判决迭代，不以包装现有编码器作为本项目核心。

## 验证与范围

公开CI完成四后端check／build／test，独立消费工程可调用API。保证以每码字错误数不超过t为前提；超过纠错半径可能误纠正，CRC32也不是密码学认证。块容器限64 KiB原始数据、1,048,576编码位，元数据需完整；不宣称支持任意BCH变体或真实存储控制器布局。
